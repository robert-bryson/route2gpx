Route to GPX

Convert routes to GPX files for GPS devices

Privacy First

This app runs entirely in your browser. There is no server — your API key and routes are kept in your browser and are never transmitted anywhere except directly to Google's API. You can keep your key for this tab only or remember it on this browser.

Keyboard Shortcuts

  • Enter in any field — Get route
  • Ctrl+Enter — Get route from anywhere
  • Escape — Exit click-to-add mode
  • Arrow keys — Pan map when focused
  • + / - — Zoom map

Tips

  • Use the buttons to set route points by clicking the map
  • Enter coordinates as lat, lng (e.g., 40.7128, -74.0060)
  • Routes persist when you refresh the page
  • GPX files work with Garmin, Wahoo, Strava, and most GPS apps
Accepted formats:
• Street address: "123 Main St, NYC"
• Place name: "Eiffel Tower, Paris"
• Coordinates: "40.7128, -74.0060"
Negative latitude is south; negative longitude is west.
